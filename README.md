# AX/PI 보드

주간회의·협의체 업무 관리용 웹 앱(PWA). 데이터는 각 기기의 브라우저에만 저장되며 이 저장소에는 업무 데이터가 없습니다.

설치: 태블릿의 Chrome 또는 Samsung 인터넷에서 GitHub Pages 주소를 열고 '홈 화면에 추가'.

## 업데이트·재설치
- 앱 안의 **'앱 다시 설치'** 버튼: 데이터를 백업 파일로 내려받은 뒤 캐시를 비우고 최신 버전으로 다시 엽니다(데이터 유지).
- 홈 화면 아이콘부터 다시 설치하려면: 먼저 '백업 내보내기' → 아이콘 길게 눌러 제거 → 주소를 다시 열고 '홈 화면에 추가' → 데이터가 비어 있으면 '백업 가져오기'.
